# Mind Atlas

I read lots of books on different subjects, i take notes while reading them, i want to imiplement a portfolio that can send strong message to recuruiters by showcasing what i have done, what i am doing, and everything around it,  Site should be very minimalistic, 
Here is the workflow, i mostly take my notes in markdown files, so the main aread responsible to render the content of my ntoes and blogs should be able to render markdown files directly.Navigation should be dynami, there will be a separate folder called master-data and it will have subfolders(representing category of notes/subject), and inside it will be all the notes as markdown files. When i create new folder or add new markdown file site should be able to understand that new note is added/removed and should be able to render it without my intervention.
